## 공통 표시 처리

### 2회차 자료해석 26~40번 추가 원본 대조

- 원본 50~78쪽과 운영 관리자 미리보기의 전체 카드 15개를 각각 직접 비교했다. 정답 번호는 모두 원본과 일치하며 변경하지 않는다.
- 26~40 해설을 원본 문장·오답분석·연산기호로 전사했다. 26번 ⑤ 및 37번 ③의 페이지 경계는 PDF 텍스트층으로 이어지는 원문을 확인했다. 풀이를 생성하거나 계산 결과를 새로 판단하지 않았다.
- 36번 ④의 누락된 `600명 이상 더`와 해설의 `3,270.5 − 2,631.8 = 638.7명 더`를 복원했다.
- 30·35번 그래프에서 빠진 제목과 단위를 일반 텍스트로 복원했다. 33·38·40번의 자료 주석은 기존 자료 이미지 안에 이미 있어 본문에 중복된 사본만 제거했다.
- 39번은 기존 자료 경로에 보기 문장만 있고 그래프 두 개가 없었다. 보기를 텍스트로 전사하고, 자료 경로를 원본 그래프 두 개로 교체했다. 새 자료는 PDF75쪽 144dpi `x=70,y=390,w=660,h=710` 범위이며 문제·보기·해설 문장은 포함하지 않는다. `public/exam-assets/pdf-verified/round-2/q-39-material.png`.
- 새 지문·해설 캡처 표시 없음. 원본 표·그래프와 일반 텍스트를 구분했다.

- 숫자 끝자리를 분모로 추정하는 변환 제거. 분수·대분수는 문항별 PDF 전사 값만 사용.
- 창의수리·수열추리 해설을 정답값 반복 문장으로 덮어쓰는 처리 제거.
- 해설 꼬리를 삭제·완성하거나 정답 문장을 새로 붙이는 처리 제거. 그 외 미복원 추출 해설이 원본과 같다는 보장은 아직 없음.
- `/admin/questions?exam=2&number=42`: 기존 관리자 인증 후 문항을 SELECT만 하는 미리보기. 결과 화면의 `QuestionCard`를 그대로 사용. 응시 기록을 생성하지 않으며, ExamRunner 실응시 화면 검수와는 별개.
