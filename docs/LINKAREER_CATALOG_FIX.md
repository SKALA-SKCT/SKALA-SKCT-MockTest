# 링커리어 회차 정정

2026년 10월 7일에 PDF 문항 링크의 원본 ID와 링커리어 목록을 대조했습니다. 기존 PDF 파일명에는 기출 반영 학기가 적혀 있어 현재 링커리어 회차명과 한 학기씩 차이가 있었습니다.

| 기존 DB ID | 원본 ID | 정정한 회차 |
| --- | --- | --- |
| 3 | 2185 | 2024년 하반기 |
| 4, 5, 6 | 2490, 2491, 2492 | 2025년 상반기 1, 2, 3회 |
| 7, 8, 9 | 2507, 2508, 2509 | 2025년 하반기 1, 2, 3회 |
| 10, 11, 12 | 2522, 2523, 2524 | 2026년 상반기 이전 등록분 |
| 13, 14, 15 | 2522, 2523, 2524 | 2026년 상반기 1, 2, 3회 |

근거는 [링커리어 SKCT 목록](https://cbt.linkareer.com/exam/detail/1231)과 각 PDF의 `onequestions` 링크입니다. 정정표는 `src/db/linkareer-catalog.ts`에 기록했습니다. 가져오기에서도 같은 표를 사용하고 중복 등록분은 제외합니다.

`npx tsx scripts/fix-exam-catalog.ts`는 제목, 문항 수와 중복 정답을 검증합니다. `--apply`를 추가하면 원본 시험 메타데이터를 `/private/tmp/skct-exam-catalog-*.json`에 백업한 후 트랜잭션으로 반영합니다. 시험 ID, 문항, 기존 답안과 점수는 보존합니다.

중복 등록분(DB ID 10, 11, 12)은 목록과 응시 기록에서 숨깁니다. 직접 주소로 응시, 결과를 열거나 저장된 기록을 변경하는 요청도 차단합니다. 문제와 응시 데이터는 DB에 그대로 보존합니다.

로컬 통합 검증은 `tests/exam-session.integration.ts`에 포함했습니다. 보관 회차의 직접 접근과 답안 변경, 중단 요청을 차단하고 DB 데이터가 유지되는지 확인합니다. 공개 회차의 재접속, 제출, 재응시도 검증합니다.
