# 링커리어 회차 정정

2026년 10월 7일에 PDF 문항 링크의 원본 ID와 링커리어 목록을 대조했습니다. 기존 PDF 파일명에는 기출 반영 학기가 적혀 있어 현재 링커리어 회차명과 한 학기씩 차이가 있었습니다.

| 기존 DB ID | 원본 ID | 정정한 회차 |
| --- | --- | --- |
| 3 | 2185 | 2024년 하반기 |
| 4, 5, 6 | 2490, 2491, 2492 | 2025년 상반기 1, 2, 3회 |
| 7, 8, 9 | 2507, 2508, 2509 | 2025년 하반기 1, 2, 3회 |
| 10, 11, 12 | 2522, 2523, 2524 | 2026년 상반기 이전 등록분 |
| 13, 14, 15 | 2522, 2523, 2524 | 2026년 상반기 1, 2, 3회 |

근거는 [링커리어 SKCT 목록](https://cbt.linkareer.com/exam/detail/1231)과 각 PDF의 `onequestions` 링크입니다. 정정표는 `src/db/linkareer-catalog.ts`에 기록했습니다. 가져오기에서도 같은 표를 사용하고 중복 등록분은 제외합니다.

`npx tsx scripts/fix-exam-catalog.ts`는 제목, 문항 수와 중복 정답을 검증합니다. `--apply`를 추가하면 원본 시험 메타데이터를 `/private/tmp/skct-exam-catalog-*.json`에 백업한 후 트랜잭션으로 반영합니다. 시험 ID, 문항, 기존 답안과 점수는 보존합니다.

중복 등록분(DB ID 10, 11, 12)은 목록에서 숨기고 직접 응시와 결과 주소를 차단합니다. 완료 기록은 같은 원본 문항을 사용하는 공개 회차(DB ID 13, 14, 15)의 결과와 통계에 합칩니다. 각 사용자의 실제 응시 시작 시각순으로 차수를 정합니다. 숨긴 회차만 풀었으면 1차 응시가 됩니다. 문제와 응시 데이터는 DB에 그대로 보존합니다.

동일성은 기존 PDF의 문항 링크와 공개 회차 수집본의 문항 링크를 순서대로 대조해 확인했습니다. 각 회차 100개씩 총 300개가 일치합니다. 회차별 정답 100개도 일치합니다. 문항 ID가 달라 결과 조회에서는 영역과 문항 번호로 답안을 대응시킵니다.

로컬 통합 검증은 `tests/exam-session.integration.ts`에 포함했습니다. 보관 회차의 직접 접근과 답안 변경, 중단 요청을 차단하고 DB 데이터가 유지되는지 확인합니다. 공개 회차의 재접속, 제출, 재응시도 검증합니다.

관리자 통계와 회원별 기록도 공개 회차로 묶습니다. 완료 기록만 응시 차수를 부여하고 미완료 기록은 별도로 표시합니다. 이전 등록분은 출처 표시를 남깁니다. 문항 선택에서는 중복 회차를 제외하고, 이전 회차 주소를 열면 같은 공개 회차 문항을 표시합니다. 신고는 공개 회차의 같은 영역과 문항 번호에 연결하며 신고 내용과 처리 상태는 각각 보존합니다. 문항의 관련 신고 링크에서 이전 등록분의 신고도 함께 확인할 수 있습니다.

`tests/exam-history.integration.ts`는 숨긴 회차만 완료한 경우와 두 회차를 모두 완료한 경우의 시간순 차수, 참여 인원, 답안 복원을 검증합니다. 관리자 응시 차수와 미완료 구분, 신고와 공개 문항의 양방향 연결, 답안과 신고 원본 보존도 확인합니다.

이 통합 검증은 시험 ID 10과 13이 비어 있는 분리된 로컬 DB에서 실행합니다. 반복 실행 전에는 로컬 앱을 중지하고 `.next/cache/fetch-cache`를 비운 뒤 다시 시작해야 이전 검증 문항의 60초 캐시가 섞이지 않습니다.
