# 문항 리뷰 챗봇 지식 정리

## 목적

문항 리뷰 챗봇이 SKCT의 명칭, 실제 시험 운영, 실전 모의고사 이용 규칙, 영역별 풀이 팁을 추측하지 않고 검색된 근거로 답하도록 한다.

상업 교재의 문제와 해설을 그대로 제공하지 않는다. 시험 안내와 풀이 원칙만 짧게 재서술하고, 답변에는 자료명과 페이지를 표시한다.

## 사용 자료

| 자료 | 확인한 범위 | 활용 내용 |
| --- | --- | --- |
| 에듀윌 취업 SKCT 2025 통합 기본서 | PDF 12~13쪽, 20~23쪽 | 인지·심층검사 구성, 온라인 응시 준비, 대표 유형 분류 |
| 해커스 SKCT 2025 통합 기본서 | PDF 17~21쪽 | 정확한 명칭, 시험 구성, 문제 이동, 시험 당일 준비, 공통 시간 관리 |
| SKCT 전자책 | PDF 10~13쪽, 23~25쪽, 32~289쪽의 관련 장 | 감점 안내, 온라인 환경, 복습법, 5개 영역별 풀이 순서와 시간 단축법 |
| SK Careers Journal | 2022년 게시물 | 인지역량 오답 감점 안내 이력 교차 확인 |
| SKALA-SKCT 실전 모의고사 | 현재 서비스 동작과 이용 안내 | 채점, 응시 흐름, 결과 통계, 채팅 기록과 문항 리뷰 범위 |

에듀윌과 해커스 PDF는 이미지형 문서라 안내·목차 페이지만 OCR한 뒤 원본 화면과 대조했다. SKCT 전자책은 텍스트 레이어에서 관련 장을 추출했다.

## 근거 우선순위

1. 실전 모의고사에 관한 질문: 현재 서비스 규칙
2. 실제 시험에 관한 질문: 최신 공식 응시 안내
3. 공식 안내가 없는 일반 정보: 연도와 페이지가 확인된 출판사 자료
4. 풀이 전략: 세 교재의 공통 원칙과 전자책의 유형별 접근법

교재끼리 구성이 다르거나 시기에 따라 바뀔 수 있는 내용은 현재도 동일하다고 단정하지 않는다. 특히 문항 수, 응시 장비, 점수 유효기간, 심층·실행역량 구성은 관계사와 채용 시기에 따라 달라질 수 있다고 안내한다.

## 실제 시험 지식

- 정확한 명칭: `SKCT(SK Competency Test)`, SK그룹 종합역량검사
- 2024년 인지검사 기준: 언어이해·자료해석·창의수리·언어추리·수열추리, 각 20문항·15분
- 온라인 시험: 프로그램 내 메모장·그림판·계산기 사용, 종이·필기구 사용 불가
- 문제 이동: 다음 문제로 건너뛸 수 있지만 이전 문제로 돌아가거나 답을 수정할 수 없다고 교재에서 안내
- 실제 시험 감점: 제공 자료와 과거 SK 채용 콘텐츠는 인지역량 오답 감점을 안내하지만 정확한 감점 산식은 확인되지 않음
- 심층역량: 정답 맞히기보다 실제 성향에 맞는 솔직하고 일관된 응답이 기본

## 실전 모의고사 서비스 지식

- 실제 SK 채용을 주관하는 공식 시험이 아니라 연습 서비스다.
- 5개 영역을 순서대로 진행하며 영역별 제한 시간은 15분이다.
- 다음 문항으로 이동하면 이전 문항으로 돌아갈 수 없다.
- 정답 1점, 오답·미응답 0점이며 추가 감점은 없다.
- `선택 n%`는 해당 선지를 고른 응시자 비율이며 점수가 아니다.
- 결과 통계는 각 사용자의 동일한 N번째 완료 기록끼리 비교하고 내 응시도 포함한다.
- 문항을 지정하면 본문·선지·정답·해설, 내 선택·풀이 시간, 응시자 통계를 근거로 답한다.
- 채팅 메시지는 서비스 DB에 저장하지 않고 현재 페이지 상태에만 보관한다. 새로고침하거나 페이지를 나가면 사라지지만, 답변 생성 시 질문과 필요한 맥락은 Gemini API로 전송된다.

## 풀이 지식

### 공통

- 문항당 평균 45초를 기준으로 연습하고, 1분 이상 걸릴 문항을 넘길 기준을 정한다.
- 해설만 읽지 않고 자신의 첫 풀이와 더 나은 풀이를 비교한 뒤 같은 문제를 다시 푼다.
- 유형별로 사용할 도구와 첫 접근 순서를 정해 반복한다.

### 언어이해

- 글의 주어·목적어·서술어와 원인·결과, 주장·근거 관계를 잡는다.
- 주제는 글 전체 방향과 결론, 빈칸은 앞뒤 논리 관계를 먼저 본다.
- 일치·추론은 선지의 서술어, 조건, 범위, 과장·축소를 본문과 비교한다.
- 배열은 대명사·접속사·예시 표현을 연결하고, 반박은 결론을 지탱하는 근거가 약해지는 지점을 찾는다.

### 자료해석

- 제목, 단위, 가로·세로축, 이미 주어진 합계를 먼저 확인한다.
- 추이·대소 비교·단순 합차는 눈과 암산으로, 정확한 비율과 복잡한 나눗셈은 계산기로 처리한다.
- 모든 선지를 계산하지 말고 빠르게 판정 가능한 선지부터 검증한다.

### 창의수리

- 농도, 가격, 경우의 수, 거리·속력·시간, 일률 중 문제 유형을 먼저 분류한다.
- 농도는 용질 보존, 가격은 정가·할인·판매가·이익 관계, 경우의 수는 OR=합·AND=곱을 사용한다.
- 거리는 `거리=속력×시간`, 일률은 `작업량÷시간`을 기준으로 필요한 식만 짧게 쓴다.

### 언어추리

- 명제는 포함 관계, 역과 대우를 구분하고 공통 중간항을 연결한다.
- 조건추리는 순서·인접·배제·동일·반대를 기호화하고 확정 조건부터 선지를 제거한다.
- 모든 경우를 만들지 말고 선지 하나를 가정한 한 가지 경우로 여러 선지를 함께 검증한다.

### 수열추리

- 차이·비율 → 홀수항·짝수항 → 묶음·반복 → 제곱·피보나치·팩토리얼 순으로 확인한다.
- 분수는 분자·분모를 따로 본 뒤 전체 연산을 확인한다.
- 소수는 정수부·소수부를 나눈 뒤 전체 규칙을 확인한다.

## 반드시 구분해 답할 질문

- `실제 SKCT에서 틀리면 감점돼?` → 실제 시험 자료와 최신 안내 필요성을 답한다.
- `여기서는 틀리면 감점돼?` → 서비스는 정답 1점, 오답·미응답 0점이라고 답한다.
- `선택 30%가 30점이야?` → 선택률이며 배점이 아니라고 답한다.
- `자료해석 4번 왜 틀렸어?` → 해당 문항 데이터만 사용한다.
